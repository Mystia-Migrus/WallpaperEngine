## 项目概述

* 系统架构: Windows
* 基本架构: Win32 + D3D12
* 主要功能: 图片, 视频, 动态 shader 壁纸
* 目标: 低消耗, 高性能, 可拓展

## 使用场景

* 桌面展示静态图片, 播放视频背景
* 全屏软件时自动暂停
* 返回桌面后恢复

## 核心功能

* 图片壁纸
* 视频壁纸
* 配置界面
* 后台低功耗

## 项目架构
设计原则:
1. 上层不能访问下层细节
2. 下层不能依赖上层
3. 每层只暴露必要接口

* App 层: 窗口启动, 状态切换, 程序配置
* Wallpaper 层: 资源管理
* Render 层: D3D12 渲染
* Media 层: 资源读取
* UI 层: 配置界面
* System 层: 日志, 配置, 资源缓存

* 配置文件采用 Json
## MVP(最小可行产品)设计

### 核心功能

* 静态壁纸
* D3D12 渲染
* 壁纸切换
* 主控窗口
* 低耗功能

### 状态设计

* Active: 程序正常运行
* Background: 程序部分遮蔽
* Hidden: 程序被完全遮蔽
* Stopped: 程序停止运行

### 阶段任务

* 第一阶段
 * 主控窗口 + 背景窗口 + 简易窗口通信
 * 静态图片功能
 * 后台状态切换
 * 基础低耗功能
